# ScreanTranslate

Программа переводит текст с экрана на русский: выделяешь область, она распознаёт текст и показывает перевод.

Для работы нужен **свой API-ключ Yandex Cloud**. Мой ключ в репозиторий не выложен, поэтому его нужно получить самому. Это бесплатно в рамках лимита Яндекса.

## 1. Как получить API-ключ

1. Зарегистрируйся на https://cloud.yandex.ru и войди в консоль.
2. Создай платёжный аккаунт. Понадобится банковская карта, но пока ты укладываешься в бесплатный лимит, деньги не списываются.
3. В консоли открой свой каталог и перейди в раздел **«Сервисные аккаунты»**.
4. Нажми **«Создать сервисный аккаунт»**, введи любое имя и выдай ему две роли:
   - `ai.translate.user`
   - `ai.vision.user`
5. Открой созданный сервисный аккаунт, нажми **«Создать новый ключ»** и выбери **«Создать API-ключ»**.
6. Скопируй ключ и сохрани. Он показывается **один раз**, потом его уже не посмотреть. Если потеряешь, создай новый.

> Названия кнопок в консоли Яндекса иногда меняются. Если что-то выглядит не так, как написано выше, ищи похожие пункты.

## 2. Куда вставить ключ

1. Найди в папке с программой (рядом с `ScreanTranslate.exe`) текстовый файл **`API_key.txt`**. Если его нет, создай файл с таким именем.
2. Открой его в блокноте.
3. Вставь ключ. Только сам ключ, без кавычек, пробелов и лишних строк.
4. Сохрани файл и запусти программу.

## 3. Запуск из исходников

1. Установи Visual Studio с поддержкой .NET 9 и WPF.
2. Открой `ScreanTranslate.sln` и собери проект.
